## Was ist EPaper / E-Akt?

Möglichkeit, anfallende Dokumente (POD, Schriftverkehr, Word-Dokumente …) **in L-Base
abzuspeichern** – mit Bezug auf:

- **Fahrt**
- **Beleg**
- **Sendung**
- **Kundennummer (Adresse)**

**Speicherbare Dokumententypen:** E-Mail · Word · PDF · Bilder (jpg, gif, png, jpeg).

## Ablauf (Schritt für Schritt, vorläufig)

1. **Zwischenspeichern lokal** am PC (z. B. Desktop) – dieser Schritt ist vorläufig nötig.
2. In L-Base über **Sendungsübersicht** oder direkt in der Sendung: links oben klicken
   (im Handout „roter Pfeil“).
3. Der **lokale Ordner/Desktop** öffnet sich automatisch → gewünschte Datei auswählen.
4. **Untertyp zwingend angeben.** Aktuell sind alle Standard-Untertypen von L-Base sichtbar –
   deshalb **nur die vier gemeinsam definierten Untertypen** verwenden (siehe unten).
5. **Betreff zwingend** mit der einheitlichen **3-Buchstaben-Abkürzung** versehen (z. B. `POD`).

**Ergebnis:** In der LA-Übersicht entsteht eine **LA vom Typ „Archiv Dokument“** mit dem
gewählten **LA-Untertyp** und dem **Betreff** (z. B. Untertyp „Ablieferbeleg“, Betreff „POD“).

## Die vier definierten LA-Untertypen (LogBATT-Pilot)

| LA-Untertyp | Kürzel | Verwendung |
|---|---|---|
| **Ablieferbeleg** | **SAB** | Ablieferbelege (POD) |
| **Beleg** (eingehender Beleg) | **BELE** | eingehende Belege |
| **Extern** | **EX** | externe Dokumente |
| **Schaden** (Schadensfoto) | **SSD** | Schadensfotos |

> Wichtig: Nur diese vier Untertypen im Pilot nutzen, auch wenn L-Base im Standard viele
> weitere anbietet.

## Betreff-Abkürzungen (3-Buchstaben-Beschlagwortung)

Aus der Basis-Schulung – **„Beschlagwortung im LBase = LA-Untertyp“**. Betreff-Kürzel je
nach Dokument (Auswahl):

| Kürzel | Bedeutung |
|---|---|
| **POD** | Ablieferbeleg (Proof of Delivery) |
| **LMS** | Lademittelschein |
| **LDL** | Ladeliste |
| **ER** | Eingangsrechnung |
| **AR** | Ausgangsrechnung |
| **GFG** | Gefahrgut |
| **ZOL** | Zoll |
| **LDA** | Ladeauftrag |
| **FRB** | Frachtbrief |
| **MES** | Messe |
| **UMZ** | Umzug |
| **PIC** | Foto |
| **DOK** | Dokumente |
| **FIM** | Finale Mail |
| **SVB** | Sondervereinbarung |
| **ANG** | Angebot |
| **KUD** | Kundendokumentation |
| **KOR** | Korrespondenz |
| **BEST-MH**, **ABHS**, **ZUST**, **AA-Stapler** | weitere Kontext-Kürzel |

> Zusammenhang: **LA-Untertyp** = *Kategorie/Ablageort* (die 4 oben), **Betreff-Kürzel** =
> *feinere Beschlagwortung* des konkreten Dokuments. Beide zusammen machen das Dokument im
> E-Akt auffindbar.
